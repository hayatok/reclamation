# 未採用の実験

mission2_departure_unaccepted.patch は v0.41 main.gd に対する段階II出発案です。現行ランタイムには適用していません。公開版の作戦条件は変更していません。

同じ獲得済み保存（518.85秒、工房HP1、部品4.4、段階III研究費支払済み）から通常費用・通常命令で比較しました。早出側は研究取消の正規返金を使い、641.85秒に出発、704秒に勝利。準備側は研究を維持し、重火器購入前の784.35秒に本部を失いました。両者とも工房が失われ、準備側は採取地防衛と収入を維持できませんでした。
