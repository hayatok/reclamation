# UI artwork provenance

Updated 2026-10-04.

## Raster illustrations

- `assets/ui/crew_equipment_atlas.png`: generated with OpenAI's built-in image-generation tool for this project, then revised with that tool to match the game's stylized low-poly world. It contains two civilian survivor portraits, a supply truck, an electrical weapon, an improvised saw weapon, and survival equipment.
- `assets/ui/title_keyart.png`: generated and revised with the same tool for this project. It depicts a salvage train, ruined industrial district, improvised electrical equipment, survivors, and distant infected silhouettes.

References were the project's earlier generated UI illustrations and a screenshot of its own gameplay. No third-party stock photographs, purchased assets, named artists' works, or copied game artwork were used as reference inputs in this pass. These are project-specific AI-generated illustrations, not renders captured from the playable scene. They should not be presented as gameplay screenshots.

## Existing SVG UI kit

The earlier panel/button/card textures and command glyphs were authored programmatically for this project as SVG geometry. They were not sourced from a third-party icon pack. This pass does not change those SVG assets.
