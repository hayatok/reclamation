# RECLAMATION salvage defenses, v08

## Origin and usage
Both assets were authored for RECLAMATION in this task. No downloaded model, paid asset, external texture, trademark, character likeness, or new account was used. The geometry is generated by the included Blender Python source and remains editable as named components in the supplied Blender scenes.

The albedo, roughness/metallic and normal atlas maps are original raster materials generated by `source/create_atlas.py` with deterministic noise, grain, scratches, weave and hand-designed hazard stripes. There are no photographic textures or external image inputs. Short labels are converted to geometry using Blender's built-in default text tooling; no external font file is distributed.

The assets can be used, edited and distributed with the RECLAMATION project, including commercial game releases. No third-party asset attribution or asset-store payment is required. This statement concerns these newly authored deliverables; it does not change the licenses of Blender, Godot, Python, Pillow or NumPy.

## Toolchain
- Blender 4.3.2: original geometry authoring, UV assignment, chamfered edges, normals, GLB export and packed editable sources
- Python 3, Pillow, NumPy: original deterministic PBR atlas generation
- Godot 4.6.3: isolated structural import verification; generated mesh LODs, texture mipmaps and compressed atlas imports

No gameplay code is contained in the GLBs. The supplied Godot project is an optional review/validation harness and is not part of the game runtime.

## Design
- Scrap gun tower: reclaimed I-section braced gantry, welded octagonal foundation, anchors, timber deck, pivot bearing, cut trunnion yoke, twin hollow muzzle assemblies and recoil rods, asymmetrical bolted scrap armor, reused power battery, feed box, cable, rear access ladder and cloth sandbags.
- Ammo workshop: patched corrugated civilian garage, asymmetrical roof, partially raised shutter, open workbench, hand press, vise, cartridge stock, component bins and transport crates, drum furnace under tapered extraction hood, flued chimney and rain cap, side extractor fan, conduit, work lamp and sagging cloth workface canopy.

Colors and wear were chosen to fit the rail-yard game's muted slate, olive, canvas and rust palette. Neither asset is intended to depict a standardized professional military installation.
