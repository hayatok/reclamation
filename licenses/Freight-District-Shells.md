# Freight district shell provenance

The sawtooth warehouse, collapsed annex and dispatch tower/loading wing are original geometry authored for RECLAMATION in `freight_district_shells.gd`. They reuse the project-owned world material palette and texture sources already documented in the repository. No third-party mesh, copied game design, paid asset or new texture is included. The editable generator is the runtime helper itself. This notice records provenance and does not add a license grant for the original game code.
