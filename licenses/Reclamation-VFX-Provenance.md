# Battlefield VFX provenance

The flash, flame, smoke, shock and scorch textures in `assets/fx/` are original deterministic procedural images created for this project from radial functions, seeded noise and color gradients. No third-party image, particle atlas or recorded effect was used. The shared-batch `battle_fx.gd` renderer is original project code.

Python, NumPy, SciPy and Pillow were creation tools, not runtime dependencies. This notice records origin; it does not grant a new distribution license to the project.
