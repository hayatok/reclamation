# Frontier district assets

The frontier district layout, canal/bridge geometry, infected warehouse and rubble geometry, visibility display and pavement shader were authored as original project code. The warehouse uses the existing project-owned ruined_plaster texture unmodified. Pavement reuses the project's deterministic grayscale surface generator. No external model, texture, audio clip, third-party logo or new font was added in this change.

Editable sources are frontier_world.gd, frontier_nest_visual.gd, frontier_pavement.gdshader, frontier_fog.gdshader and the associated controller/presentation files. The district also uses existing original freight, survivor and ruined-building assets whose provenance is retained in the project licenses and art_source directories.

This provenance record identifies origin; it does not introduce a new license grant for the original game code or assets. Existing third-party font/engine notices retain their respective terms.
