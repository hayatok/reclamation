# 成長選択と次の候補

導電跳躍・誘爆装薬・分岐斉射・同期砲列・雷光網・連鎖解体・地平線斉射・歩く工廠の8枚は、採用すると後続の候補補充対象の系統を切り替える。この既存の効果を、該当カードだけに2行で表示した。分岐斉射は武器種が実弾でも補充対象は機動・補給系であり、装備の必要条件だけでは分からなかった。

抽選規則は変更していない。同系統が初回候補に3回続けて出なかった後、取得可能な同系統を次の抽選で補充する。候補更新は未出回数を増減しない。上限到達や前提不足で有効な装備がなければ補充しない。表示は毎回の出現率上昇、特定装備の保証、装備そのものの無償獲得を約束しない。

獲得済みM2保存から、表示・保留再開・候補更新・採用・保存再開の全保存状態を改善前後で比較し完全一致した。乱数・部隊・資源・強化・候補も比較対象。既存の抽選規則試験と、スマホ相当の入力中断/再開/二重採用防止試験も通過した。

実Godot画面のPC幅約1180とスマホ相当844×390・390×844を確認。小さいPC画面は説明のためにカード図の高さを40px調整し、採用欄のはみ出しを解消した。モバイルの独立画面レビューも受入。実スマホ/Web/Mac、初見の理解度や戦術の楽しさを検証したものではなく、ビルド多様性の証明でもない。
