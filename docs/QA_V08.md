# 0.8 検証範囲

## 実装と実描画
- 避難用車両拠点、廃材砲塔、弾薬工房、補給車、輸送車、破断水道管、崩壊舗装をBlender→GLBで置換。
- 通常感染者の18ボーン原型から歩行・攻撃・倒れる動作を焼き込み、32ポーズの共有MultiMesh描画。遠景約520三角形、近景3,337三角形。
- Godot 4.6.3 Compatibilityの実レンダリングでモデルと統合戦闘を確認。比較用の戦闘は通常プレイで獲得した終盤セーブを使用。画像用の無料資源や強制強化は加えていない。
- アート差替えのみの段階では、201時点の保存状態が以前の版と完全一致した。

## 感染者の接近
同じA*経路の中心へ重なる敵に横方向回避を追加。局所的な列幅は0.601→0.828m、敵同士の間隔中央値は0.190→0.509mへ変化した。最寄りの空きマスが建物間の閉鎖領域にある場合、到達可能な別の接近点を選ぶ。障害物の角を斜めに抜けないことも確認。

同じ獲得済みセーブを再生した限定確認では、長時間停止・通行不可セル侵入・調べた移動区間の角抜けはいずれも0件。最終作戦は427.5秒で達成し、15人と拠点を維持、7発砲撃を保持。輸送作戦では護衛ありの最低車両HP1000に対して、拠点待機では127で、護衛の意味を保った。これらは加速シミュレーションによる確認で、全プレイヤーの難易度評価ではない。

## 回帰
`tests/check_crowd_steering.gd`、集中攻撃18項目、解体29項目が通過。急速なヘッドレス終了では既知のObjectDB/resource終了時警告が残る。通常の実描画でスクリプトエラーは発生しなかった。

## 性能と未確認範囲
最終150フレームのオフライン動画はllvmpipeソフトウェア描画でGPU平均約303ms/フレーム。動画の30fpsは固定出力設定であり、リアルタイム性能の証明ではない。軽量設定では感染者を遠景メッシュへ固定する。実GPU、実Mac、初見プレイヤーの操作・難易度評価、音の聴感は未確認。公開Web版の起動検証は配信後に別途実施する。
