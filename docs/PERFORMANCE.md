# 描画計測（0.4の比較値）

Godot4.6.3 / Compatibility / Mesa llvmpipe（ソフトウェア描画）。ネイティブ画面で成長済み部隊と感染群を描画した。各試験380フレーム。途中の画像保存があるため、厳密なベンチマークではなく、この環境での比較値。

| 条件 | 平均フレーム | 平均描画呼出 | 平均プリミティブ | スクリプト処理 |
|---|---:|---:|---:|---:|
| 250体・画質優先 |131.0ms|485|132k|未分離|
| 500体・画質優先・変更前 |132.1ms|540|166k|11.5ms|
| 500体・動作優先 |126.0ms|540|152k|12.2ms|
| 500体・画質優先・味方一括描画 |131.5ms|429|161k|11.0ms|

最後の変更は生存者・作業員・爆薬手の6部位を種類ごとにMultiMeshへまとめたもの。同じモデル、材質、骨格の変換を利用。描画呼出は約21%減り、500体撃破の結果も一致したが、このソフトウェア描画環境でFPS改善を実証したわけではない。

動作優先は3D解像度75%、短時間残る倒れた感染者を96体から32体へ制限し、影の設定を簡素化する。UIの解像度、戦闘計算、成長、目標は変えない。

戦闘シミュレーションは平均約9–10ms。残りのフレーム時間にはレンダラー、ドライバー、同期や表示の待ちが含まれ、独立したGPU時間とは呼べない。平均プリミティブ数だけから特定素材のコストを断定しない。

通常GPUや対象Macでの性能は未確認。この環境では大群時の応答性が低く、商用向けの性能確認を通過したとは扱っていない。

0.5では遮蔽する建物を個別の材質で透過させる処理が追加された。この表を0.5最終版の性能測定として流用しない。0.5の動画はオフライン固定フレーム録画であり、実行性能の証拠ではない。
