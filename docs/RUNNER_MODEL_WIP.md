# 疾走体の専用モデルと走行品質

従来の6部位を丸ごと振る疾走体を、低く前へ出る頭と肩、膝を畳んで戻す脚、蹴り出す脚を持つ原作モデルへ替えました。通常距離での移動表現を受け入れた開発checkpointです。公開版は0.53のままで、次の累積公開に含める予定です。

## 実際の進軍で確認した違い

獲得済みの広域M2セーブから同じ4人に同じ攻撃移動を指示し、通常倍率50・1180×737で旧描画と新描画を比較しました。6秒ずつの連続する2区間で、開始・終了の全保存状態が一致しました。敵数・速度・攻撃時刻・ダメージ・成長抽選・操作は変更していません。

独立した画面レビューで、直立した棒状の列から前傾した走行姿勢への変化、伸ばす脚と畳む脚の区別を確認しました。色の主張は弱まりますが、姿勢による通常感染者との違いが読め、部隊・道路・霧の視認性を妨げません。動画は固定ステップ30Hzの記録であり、実行時30fpsの証拠ではありません。

[変更前](evidence/runner_motion/before.mp4) / [変更後](evidence/runner_motion/after.mp4)。追加区間でも敵は射撃で減り、残群は本拠方向へ進みました。近接接触は記録されていないため、実戦での攻撃動作の視認性は未確認です。接触時刻と死亡配置のヘルパー検証は別に通っています。

## 描画コスト

ネイティブllvmpipeで同じ200体・位置・速度・照明・カメラを使い、旧→新→旧→新の4回を比較しました。各30フレーム準備後の90フレームを測定し、画像保存は測定に含めていません。

- フレーム時間の平均：63.96 → 48.89 ms。両比較とも新描画が短縮。
- 描画更新CPU：2.14 → 2.98 ms。CPU側は0.84 ms増加。
- 描画呼出：9 → 平均13.33。三角形等の描画primitive：130,404 → 63,888。
- 毎フレーム200体が表示されました。両モデルは両条件で読み込み済みなので、メモリ低減の主張はしません。

これは既存の遠景LOD・影方針を含めた実装全体の比較です。旧側は胴の影あり、新側の遠景は既存のbaked方式に合わせ影なしです。実GPU・Web・Mac・スマホの性能結果ではありません。

## 制作と残る範囲

近景1328／遠景312三角形、2待機・12走行・6攻撃・8死亡姿勢を共有し、敵ごとの骨格や物理は増やしていません。通常感染者と重装体のモデルは変更していません。

編集用Blender原本はscene datablockだけを書き出し、UI履歴を含めずに同梱しました。別プロセスで再度開き、骨格・頂点・UV・ウェイト・材質・走行姿勢が元と一致することを確認しました。実行用GLBは清掃前後で不変です。

[制作元・再生成手順](../art_source/runner_reconstruction/README.md)。急な方向転換時の足の滑り、通常距離での近接攻撃、実端末と初見の人による評価は残ります。一般的なheadless終了時ObjectDB警告は解決済みとは扱っていません。
