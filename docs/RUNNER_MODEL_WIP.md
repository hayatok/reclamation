# 疾走体の専用モデル・走行姿勢（未受入）

通常感染者と比べて、疾走体は従来の6部位を丸ごと振る動きが残っています。通常距離での膝・肘・蹴り出しの違いを目標として、専用の原作モデルと共有姿勢を追加した開発途中のcheckpointです。

- 近景1328／遠景312三角形。2待機・12走行・6攻撃・8死亡の姿勢を共有します。
- 実行時に敵ごとの骨格・物理を増やさず、既存の移動距離に対応した姿勢選択とGPU補間を使います。
- 通常感染者・重装体、移動速度・攻撃時刻・ダメージなどのゲーム状態は編集していません。旧描画へ戻せる入口も残っています。
- GLB形式、姿勢対応、通常感染者の共有キャッシュとの分離、死亡分類と接触時刻のヘルパー検証は通りました。ネイティブ単体プレビューで欠損材質がなく関節の形が読めることまで確認しました。
- 実際の獲得済み戦闘での同カメラ前後動画、統合状態比較、群れの描画負荷はまだ受入前です。実Web・スマホ・Mac・実GPUの結果ではありません。

[制作元・再生成手順と来歴](../art_source/runner_reconstruction/README.md)。通常の公開版は0.53です。このcheckpointだけでPagesを更新しません。

編集用Blender原本はエディター内のパス情報を整理中のため、このcheckpointでは未同梱です。モデル・姿勢を再生成する制作Python、材質、実行用GLBは含めています。
