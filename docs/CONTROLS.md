# 操作

- 左クリック・ドラッグで選択。Shiftで追加。1は戦闘員、2は作業員。
- 地面を右クリックすると移動。感染者を右クリックすると、選んだ戦闘員がその敵を集中攻撃する。射程外なら追い、射程に入ると止まって撃つ。
- Gを押して地面を右クリックすると攻撃移動。遭遇した敵を迎撃しながら進む。
- 作業員で残骸を右クリックして回収。施設を右クリックして復旧。未完成の建物を右クリックすると工事を再開する。
- 下の「仲間・指示」「拠点・工作」で生産と建設を選ぶ。表示された費用を使う。Backspaceは最後の生産予約を取り消す。
- Fで発電を開始・停止。発電の騒音は群れを引き寄せる。
- 建物を選ぶと状態が表示される。工房の稼働切替と「解体」もここから。解体は表示された回収額を一度確認して実行する。Shift+Deleteでも確認を開く。
- 完成した建物の解体回収は最大50%。損傷すると減る。工事中は進捗に応じて回収。本拠点と復旧対象の施設は撤去できない。
- 輸送作戦では道路を選んで出発。車列の停車・再発進で護衛を集め直せる。襲撃の方向と残り時間は作戦欄とミニマップで確認する。
- 矢印で視点移動、ホイールで拡大縮小。ミニマップをクリックして視点を移す。
- Spaceで戦術ポーズ。停止中も指示できる。F6で保存し、タイトルから再開する。
- 成長時は3候補から一つ選ぶ。1・2・3キーでも採用できる。
