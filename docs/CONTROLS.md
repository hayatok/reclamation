# 操作

- 左クリックで1対象、ドラッグで複数の部隊を選択。Shiftで追加・解除。
- 下部のコマンドは選択対象に応じて変わる。本部なら作業員と発展、訓練所なら軍備、作業員なら建築、戦闘員なら移動・戦闘。
- ボタンに表示されたキーでそのコマンドを実行する（4列: Q/W/E/R、A/S/D/F）。選択していない施設から生産する共通ショートカットはない。
- 生産施設を選んで地面を右クリックすると集合地点を設定。本部から資源を指定すると、新しい作業員は採取を開始する。
- 作業員で資源を右クリックして採取、未完成の建物で工事、損傷した建物で修理。復旧対象の設備も右クリックで指示する。
- 部隊で地面を右クリックすると移動、敵なら集中攻撃、仲間なら継続護衛。攻撃移動は選択中のコマンドから目的地を指定する。
- Ctrl+1〜9で選択した部隊、または味方建物1つをグループ登録。登録は上書き。1〜9で現在の選択を置き換えて呼び出す。同じ番号を350ms以内に2回押すと生存メンバーの中央へ視点を移動する。1回だけなら視点は動かない。Shift付きの番号キーは使わない。
- 例: 西側の守備隊をCtrl+1、東側をCtrl+2、訓練所をCtrl+3へ登録。1か2で守備隊を選んで右クリックで指示、3のあとQでその訓練所に生存者を予約する。呼出自体は以前の移動・戦闘・採取命令を変更しない。
- Hで本部を選択・表示。ピリオド(.)か上部の「待機」ボタンで次の待機作業員。Cは全戦闘員、Vは全作業員を選択。
- 矢印で視点移動、ホイールで拡大縮小。ミニマップをクリックして視点移動。
- Spaceで戦術停止。停止中も命令できる。Esc・右クリックで建築配置を取消。
- 生産施設の「予約を取消」またはBackspaceで最後の予約を返金。解体は建物を選び、表示された返金額を一度確認して行う。Shift+Deleteでも開く。
- 上部メニューから保存・設定・作戦選択。F6でも保存。タイトルから再開。基盤変更により保存形式は2。0.8の保存は0.8リリースで利用する。
- 強化画面では番号キーより候補選択を優先し、修飾キーなしの1・2・3で採用する。Ctrl+番号でグループを変更しない。Escで保留して戻る。
- 登録グループは途中保存に含まれる。倒れた部隊・失った建物は呼出と保存から除外する。空の番号や全滅したグループの呼出は現在の選択を変えない。登録対象を選んでいないときのCtrl+番号も登録を変えない。

現在の保存先は `user://settlement_v2/`。旧版の保存・進行・設定を上書きしない。続きからはこの専用領域の保存だけを読む。


建物・作業員への攻撃表示はクリックで現場へ視点を移します。部隊の選択や命令は変えません。途中保存からの再開は保存時の視点と拡大率を戻します。

## 作業員の連続命令

- Shift+右クリックで、選択中の作業員に移動・建設・修理・採取を順番に予約できます。最大16件。混成選択の戦闘員には命令しません。護衛・復旧設備の予約と、護衛中の作業員への予約には未対応です。
- 建物の配置中にShift+左クリックすると、一度だけ費用を払い、建設を予約します。同じ建物のプレビューが残るので続けて配置できます。別の建物のキーで切替、Escまたは右クリックでプレビューだけ取消。
- 普通の右クリックや普通の建設配置は、今の命令と予約を置き換えます。「停止」は予約も解除し、持っている資源は保持します。支払済みの基礎は残ります。取り消す場合は既存の解体操作を使います。
- 採取中に次の作業を予約した場合、次の搬入を終えてから進みます。資源がなく手持ちも空の待機なら即座に進み、搬入できないときは資源と予約を保持します。予約から新たに始めた採取は、その採取を実際に行って搬入するまで次へ進みません。
- 建設・修理の連続予約を終えると元の採取へ戻ります。明示した採取予約が始まると、その採取先を使います。壊れた予約先や他の作業員が完了した建設は飛ばし、通路や作業場所が塞がれている仕事は待ちます。
- 画面下の現在命令と予約件数・次の作業を確認できます。経路線は現在の作業だけを表示します。予約と支払済みの基礎、運搬中の資源は途中保存に含まれます。
