# 強化選択中の保存をスマホ幅で再開する

保存済み開発基点の護衛命令と広域第2作戦を再起動し、保存再開を確認した。以前のローカル専用候補を完全復元したという意味ではなく、確認可能なソースからの限定修正である。

## プレイヤーに見えていた問題

強化候補を開いたまま保存すると、再開処理がカード画面を先に作り、後からスマホHUDを追加していた。資源バーがカードのタイトルと説明を隠し、命令欄が候補更新・後回しの操作に重なった。

カードをスマホ表示へ初めて整える際、HUDより古い兄弟要素なら一度だけ前へ移す。描画順だけでなくGUIの入力対象も一致する。毎フレーム上に移動させず、通常の操作パネルや後で作られた画面の順序を変えない。候補抽選・成長効果・ゲーム速度は変更していない。

## 確認

保存済みの通常攻略720.35秒から既存命令を進め、747.15秒に自然に得たLv9の「同期砲列・延伸照準・自動回収給弾」を開いて保存。同じデータを使ったクラウドネイティブ描画で、修正前はカードindex10/HUD11、修正後はカード11/HUD10。候補と乱数状態は完全に同じ。

844×390と390×844で再開、候補更新、後回しと再表示、再保存・再読込を確認。以前HUDが占めた位置のGUI入力先がカード側になること、タッチ由来の押下が回転で中断されると採用されないこと、新たなタップで一度だけ採用されることを確認した。実機タッチではなく合成入力である。実iPhone/Android、実WebGPU性能、音声の実聴は未確認。
