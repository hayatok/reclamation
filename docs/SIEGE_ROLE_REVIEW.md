# 攻城と護衛の限定比較

同じ通常費用の段階III出発保存から、既存の命令と、遠征中の歩兵・爆薬手9人を迫撃車へ護衛させる命令一手を比較しました。部隊・資源・強化・敵の注入はなく、どちらも新しい成長候補は既存の保留機能で先送りしました。最大120秒ずつのheadless進行で、人間の楽しさや実操作映像の検証ではありません。

元の進軍は53.95秒で巣を破壊し、迫撃車も42.60秒から巣の中心付近へ砲弾4発を発射しました。以前の通し記録の「迫撃車の到着前に決着」は、この現行状態では再現していません。

護衛側は120秒で巣の耐久2743.992が残りました。巣の中心付近への砲弾は28発ですが、これは発射数であって命中数や与ダメージの帰属ではありません。両側とも遠征9人は全員生存・合計耐久1128、本部1000、迫撃車288で、安全性の向上は確認できません。

護衛側の歩兵・爆薬手は巣から19.52〜24.68m。射程10.5m・13mの外に留まるため、射程22mの迫撃車を守る判断が、巣への直接火力を減らす結果と一致します。時間が違うので、撃破数や弾薬備蓄の下限を効率の優劣として比較しません。

この結果だけで攻城ボーナス・新敵・火力調整は加えません。次の読み取り改善候補は、単体選択時に自軍の実際の射程を地面で示し、前進と護衛の判断材料にすることです。全員分の輪や恒常的な数値壁は作りません。
