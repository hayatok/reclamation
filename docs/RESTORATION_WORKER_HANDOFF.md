# 設備復旧後の採取引継ぎ

採取班を発電所・揚水場・変電所の復旧に回したとき、完成後に元の採取へ戻ります。建設や廃棄倉庫と同じ引継ぎです。明示した次の予約が優先され、普通の移動・停止・新しい採取命令は以前の仕事を置き換えます。持っている資源を消したり、その場で搬入した扱いにはしません。

修正前は通常設備だけ採取先を消し、完了後に待機していました。過去の操作記録 PLAYTHROUGH_V31 にも、揚水場の後へ採取を手動予約した記録があります。

## 確認した変化

クラウド Godot 4.6.3、1180×737 の同じ制御場面で、選択した採取員へ通常の右クリックで発電所復旧を指示しました。復旧前98%・支払済み・段階IIを設定した限定再現であり、通常攻略の通しではありません。実際の通路と作業場所予約を経由して残りの作業を完了させると、旧版は「待機」、修正版は「食料 採取へ移動」になりました。追加の採取指示はしていません。画像と状態は evidence/restoration_handoff にあります。

最初の撮影用セットアップは作業員を設備の占有セル内へ置いており、経路なしになったため比較には使いませんでした。採用した比較は元の初期位置から実経路を進めています。

限定回帰では3施設への実命令・移動・支払・作業、異なる荷物の保持、予約採取/移動/建設の優先、複数担当、命令変更、無効な設備と段階不足、途中保存からの仕事の継続を確認しました。費用・所要時間・敵や勝利条件は変更していません。

実スマホ、実Web、Macの操作や人間初見の分かりやすさは未確認です。新しい常時UIは追加していません。
