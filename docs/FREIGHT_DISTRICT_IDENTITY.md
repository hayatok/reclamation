# 貨物地区の建物シルエット

公開0.53を基点とする開発checkpointです。広域M2の貨物地区にあった同じ事務所型の3棟を、鋸歯屋根の荷役倉庫、倒壊した低い上屋、管制塔と荷捌き棟に変更しました。既存の線路・廃貨車と合わせて地区の用途を読み取りやすくします。

既存の敷地、障害物、屋根高さの範囲に収めています。道路・通行判定・敵・視界・資源・費用・カメラに変更はありません。既存の建物ごとの統合描画と遮蔽透過を利用し、新しいテクスチャや照明は追加していません。

## 確認

通常の偵察命令で南橋を渡った4人の保存を使用し、通常倍率50、1180×737の同じカメラで前後比較しました。3場面とも保存状態全体が一致します。実画面では屋根・建物の大きな形状が区別でき、部隊・選択リング・道路・霧の視認性を妨げる新しい問題は確認されませんでした。管制塔は以前より健全に見えますが、崩れた低層部と廃貨車を含む廃施設として受け入れています。

描画プリミティブは54199→51799、56221→52261、58505→55205。draw callは280→280、276→277、282→283です。これはクラウドllvmpipe上の静止描画量であり、FPS改善や実端末性能の証明ではありません。実Web・スマホ・Mac・実GPU、人間初見と音の実聴は未確認です。

画像と同条件比較: [evidence/freight_district/comparison.json](evidence/freight_district/comparison.json)。構造検証: `tests/check_freight_district_shells.gd`。再描画: `tests/review_freight_district.gd`。

## 参照した開発者資料

ValveのJason Mitchellによる[GDC2008 Stylization with a Purpose](https://cdn.fastly.steamstatic.com/apps/valve/2008/GDC2008_StylizationWithAPurpose_TF2.pdf)では、最初に読める輪郭と情報の優先度、環境の形状・材質による区別を説明しています。この変更では細部追加より屋根と建物全体の形を優先しました。資料のアセットや固有の意匠は使用していません。
