# 完成範囲と、実際に残る確認

## 機能・内容

復旧防衛、二つの輸送路と護衛、三施設の最終送電・大型感染者の三作戦を実装。24種の共有成長、研究と重火器、生産・送電・回収、集中攻撃、解体、保存・再開、勝敗・次作戦までが動く。通常資源と提示された成長を使う命令実行で達成を確認し、代表操作は実画面でも確認した。

群れを隠す建物の透過、砲撃の成長、射撃・作業・倒れる動き、オリジナルSE、短い作戦前後の物語を含む。現段階で新しい作戦・装備・画面を追加し続けることはしない。

## 残る確認

- 対象GPUの実行性能。現在のクラウドはソフトウェア描画であり、快適な大群描画を認定できない。
- Mac実機とブラウザーでの起動・入力・保存・連続プレイ。配布物の構造やPCK起動を確認したこととは別。
- 実際に聴いた音量、距離感、連続射撃時の密度。録画に音が入ることや数値上のクリッピング確認は、聴感評価の代わりにはならない。
- 初見の人が三作戦を通して遊ぶこと。操作理解、研究・護衛の判断、難易度とテンポをそこで確認する。熟知した自動手順の勝利を初見の楽しさの証明にはしない。

人が試せる候補であり、商用品質の認定済みという扱いではない。次の変更は具体的な試遊結果や実機の問題を基に決める。
