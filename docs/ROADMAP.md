# 現在の範囲と次の検証

開発版0.2は、短い3作戦を開始から結末まで遊べる範囲です。24種の軍団改装、3つの実戦構成、復旧と補給と防衛、途中保存が含まれます。

次の優先順位は、機能の追加よりプレイ上の検証です。

1. 初見のプレイヤーが、工兵の護衛、工廠の資材消費、送電距離、軍団改装を理解して判断できるか。
2. MacとWebの実機起動、音、入力、保存、通常GPUの性能。
3. 新しいHUDと250体級の戦闘で、目標・部隊・進路が読めるか。
4. 長時間の連続プレイと、再開・敗北・再挑戦を重ねた際の安定性。

最初の企画全量に対しては、長編キャンペーン、演出的な物語、より細かな補給網、専用のアニメーション・音楽・シネマティック、商用ストア配布の認証や公証は含みません。これらは現在の短編が遊びとして成立するかを確認してから範囲を決めます。
