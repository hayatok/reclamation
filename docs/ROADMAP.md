# 完成範囲と、実際に残る確認

## 0.9で変更した基盤

三作戦の復旧・護衛・最終送電と24種の共有成長を保ちながら、拠点を育てる仕組みを作り直した。食料・廃材・部品の運搬経済、住居と人口、三段階の発展、建物ごとの生産予約、選択対象ごとの操作、集合地点、近距離に限定した資源再配置、保存形式2を実装した。新しい5施設と移動迫撃車には編集可能な立体モデルを用意した。

通常資源から命令を実行する加速シミュレーションで三作戦の達成を確認し、代表的な本部・作業員・住居・訓練所操作は実画面で確認した。詳細と試験したソースの境界は[QA_V09.md](QA_V09.md)を参照。以前の「機能追加を止める」という記述は当時の方針で、0.9の経済改修を完了済みとする代わりにはならない。

## 次に確かめること

- 対象GPUでの大群描画と入力応答。クラウドのソフトウェア描画では快適性を認定できない。
- Mac実機と公開Web配布物の起動、入力、保存・再開、連続プレイ。配布物の構造確認・ヘッドレス起動とは別に試す。
- 実際に聴いた音量、距離感、連続射撃と工業音の密度。音入り録画やクリッピングの数値だけでは判断しない。
- 初見の人による三作戦。採取の再配置、住宅喪失、部品の競合、発展の待ち行列、護衛を理解できるか。作戦3の29分台という自動経路結果も含め、損失からの回復とテンポを見る。
- 操作の仮説: 複数の採取場と防衛隊を扱う際にコントロールグループが必要か、既存の全軍/全作業員選択・待機巡回でどこまで扱えるかを観察する。
- 割込みの仮説: 大群戦で強化カードが作戦判断を頻繁に止めないか、重要な通知を見逃さないかを観察する。

コントロールグループ追加やカード仕様変更は、この段階では確約しない。実測と人の試遊から必要な変更を絞る。商用品質の認定済みという扱いではない。
