# RECLAMATION v0.2 ゲームロジックQA

検証日:2026年10月4日。クラウド上のGodot4.6.3で実施。v0.1の実画面検証とは区別する。

## 結論

24種の強化、補給・電力・生産、保存状態の独立数値試験は合格。雷撃・爆発・移動補給の異なる構成で、通常命令と獲得資源による作戦勝利を確認した。作戦3の移動補給構成は雷撃・爆発を取得せず、補給車・歩く工廠・部隊増産・護衛分割で成立した。

この報告はゲームロジックの検証。描画性能、完成美術、刷新後のUIの見た目をヘッドレス実行から評価していない。

## 実行した試験

### 全24強化:210の数値アサーション

- 戦闘16件:威力、射撃間隔、射程、貫通、爆発半径、クリティカル、追加弾、連鎖、撃破爆発、クリティカル倍率、警戒時火力、斉射、雷光網、連鎖解体、地平線斉射。
- 支援・経済194件:耐久増加、移動、弾薬節約、回収、建設・生産、発電容量、補修、撃破時生産加速、歩く工廠。生産予約、取消返金、工廠の資材消費と弾薬出力、電力割当、代替報酬も含む。
- 数値を隔離する試験では強化や敵配置を直接設定した。後述の通常プレイ試験とは別の証拠である。

### 保存の完全往復

JSON34項目が保存前後で一致。新しい弾薬、再抽選回数、建設・生産ブースト、生産予約、優先系統と救済回数、未処理爆発、装甲敵、帯電期限も確認した。提示カード、乱数、命令、XPを保持し、カードは二重適用されない。不正JSONと必須項目欠落は現在の世界を壊さず拒否する。

### 建設の回復

工兵を失った未完成工廠に、別の工兵で右クリックして建設を再開できる。再課金はなく、完成まで進んだ。これは既存機能であり、今回の新規修正事項には含めない。

### 3構成の実戦成立

高速化した通常ゲーム処理で、回収・建設・生産予約・移動・護衛・施設復旧・電源操作と、実際に提示されたカード選択だけを使った。無料資源、無敵、目標の直接上書きは使っていない。

- 雷撃:作戦1で導電跳躍と雷光網に到達し、4分35秒・1,132撃破・Lv19で勝利。
- 爆発:作戦2で誘爆装薬、広域弾頭、連鎖解体に到達し、6分08秒・2,911撃破・Lv32で勝利。
- 移動補給:作戦3で歩く工廠、補給車、分岐斉射、戦闘補修、自動回収給弾を組み合わせ、7分04秒・4,173撃破・Lv39で勝利。最終本拠点耐久1,100、回収1,300、弾薬約399。雷撃・誘爆を使わない構成。

作戦3では発電所から南側工廠へ直接は電力が届かない。中継設備で接続し、工廠2基を完成させた。また全軍で護衛に出ると本拠点を失った。通常の生産予約で警備兵4人を補充し、4人を護衛へ、残りを拠点防衛へ分けた試行は勝利した。補給と部隊配分が結果を変えている。

初期の失敗試行には、工兵の死亡を補充しない、建設途中で別作業へ命令し直す、発電範囲外の工廠を放置するなど、テスト側の弱い指揮も含む。これらをゲームの不具合や勝利不能の証拠にはしていない。

## 発見して修正を確認した実際の不具合

1. 防衛塔の貫通・斉射が高い発射点から地面へ向く3D方向で判定され、一直線の敵を外した。地上平面で判定するよう修正。貫通2体と斉射6体の実ダメージを確認。
2. 補修が死亡判定より先に処理され、致死ダメージを受けた兵士・塔が復活した。耐久0以下を回復しないよう修正。実際の敵攻撃で負の耐久となった兵士が次フレームで除去されることまで確認。
3. 歩く工廠の弾薬軽減が塔にも適用された。説明どおり班だけに限定。
4. 過負荷火力と歩く工廠の条件付き威力を乗算していた。仕様の同枠加算・上限へ整理。
5. 同じ場所にいる敵同士の連鎖でゼロ長ビームが描画エラーを出した。ゼロ長の演出だけを省き、ダメージは維持。

また、設備起動前から作戦倍率で圧力が増す初期調整は、起動前の準備時間を確保する方向へ変更された。設備起動後の作戦倍率と初回増援は残る。

## 0.3の追加検証

- 第三作戦を含む33波で、予告される方向集合と実際の全出現方向が一致。
- 24装備の採用後プレビュー、初回案内の段階、選択命令、工廠の停止理由、重要警告の専用音声枠をテスト。

- 210項目の戦闘・支援と、34項目の保存を再実行して通過。
- 新しい比較表示を含む装備画面を実表示し、保存された選択から再開できることを確認。
- 命中反応用の試作シェーダーで通常の敵材質が暗くなる問題を実画面で発見したため撤回。元の材質に戻し、反動と短い局所火花を採用。修正後の250体試験を再描画し、250体撃破まで進行。

このクラウド実行環境には利用できる音声出力デバイスがなかった。音声枠の再生状態はテストしたが、実際に聞いた音量・音質の評価とは区別する。初見プレイヤーの理解と操作感は引き続き人による試遊が必要。
