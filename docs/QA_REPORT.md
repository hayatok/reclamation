# v0.4 検証結果

## 実戦

通常の資源収入・命令・提示された成長候補を使った高速実行で、作戦2は3分39秒、作戦3は7分07秒で達成。資源や施設復旧の状態を与えた展示シーンとは別の検証。

- 輸送任務：回収所・工房・研究・臼砲・爆薬手を費用を払って整備。合法な建設で車列が永久停止する問題を発見し、同じ配置のまま修正後の到着まで確認。
- 最終任務：三施設の復旧、180秒の送電、破砕体の撃破を達成。臼砲72発・爆薬手64発、4,401体撃破。破砕体は1.4秒の予告後に臼砲を損傷させ、その後部隊が撃破し、補修で回復。
- 実際の画面操作：作戦1の選択、移動、回収、建設、作業変更・建設再開、施設復旧、発電開始、成長選択、保存とポーズを確認。

## 状態と不具合修正

研究・重火器・回収所の23項目、および輸送・大型感染者の状態遷移を確認。新兵科に補給効果が漏れる問題、新防衛設備が補修対象から外れる問題、死亡と目標達成が同じフレームに起きたとき誤って勝利になる問題を修正。

保存・再開では研究、車列の区間、破砕体の攻撃予告位置、飛翔中の砲弾の時間・威力・半径が復元されることを確認。

## 表現と確認範囲

崩落した建物、民間の継ぎはぎ装備、感染群、成長済み部隊の250体戦闘をネイティブ画面で描画。画面例は配置済みの描画確認シーンであり、通常プレイの記録ではない。

クラウドはllvmpipeソフトウェアレンダラー。実GPU性能、Mac実機、ブラウザー実行、複数人による初見試遊は未確認。作戦2・3の実戦は命令を高速実行したもので、マウス操作による通しプレイとは区別する。

SEは52素材の読み込み、再生イベント、優先度・音量制御を確認した。クラウドに音声出力機器がないため、実機での聴感評価は未完了。
