# 旧税関前の車両・荷扱い区画

元の空白舗装へ、4台分の区画と既存道路につながる開口を自作しました。通常距離で建物前の用途が読める、控えめな空間構成の改善です。港専用意匠や終末感の大幅強化とは評価しません。

`before.png` / `after.png` は同じ獲得済み M2 セーブ、1180×738、同カメラです。独立の通常倍率レビューで、部隊と感染倉庫の視認性を保ち、旧用途を読み取れると評価しました。小物・障害物・文字は追加していません。

既存の不透明な道路/区画線材質と静的バッチへ16箱を追加。ナビ、通路、資源、カメラ、RNG、ゲームルールは変更なし。同セーブ40ステップ後の全保存状態が一致し、新規作戦の未踏域を見た画像は前後でバイト一致しました。これは限定 native 検査であり、実Web/スマホ/Macの品質や性能を保証しません。

原本は v0.66.0 の確定ソースです。以前失われた背景変更と同じバイトの復元ではありません。未採用の迫撃車改造、中央送電所の戦闘試作、未実聴音楽は含みません。既存の終了時 ObjectDB 警告は残ります。
