The generated runtime OTF is byte-identical to the earlier locally verified font: 352,736 bytes, SHA256 db4bb368fb6b7938a06a8c82a21448b43f25342d232265e56185ccff4373c88c. The complete original collection remains in source, with its original license. The modified font family is Reclamation UI JP.

Fresh native Godot captures of headquarters, workers and growth choices are pixel-identical before/after replacement. The world was disabled only in the comparison fixture to isolate UI. Source coverage includes the current659 characters. Runtime export excludes the original collection and includes both license notices. New export sizes and actual browser/phone startup remain to be measured for this reconstructed candidate; prior full-build byte counts are not claimed as current results.

Before export, run the coverage check described in AGENTS.md. New free-text input or languages require a new coverage review; this subset is for the game's fixed UI, not arbitrary Japanese text.
