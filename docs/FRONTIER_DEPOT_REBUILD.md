# 任意の前線倉庫（再構築）

第2作戦の北西資源地に、作業員で復旧できる廃棄倉庫を追加しました。廃材50・部品10、作業員1人の基準作業時間12秒。通常の集積所新設は廃材60・25秒。固定位置を早く使うか、部品を使わず自由な場所に建てるかを選ぶ。勝利条件は感染源の破壊のまま。

未探索では非表示。近くには既存の感染者キャンプがあり、復旧地点は安全を保証しない。復旧後は通常の資材集積所になり、搬入・被攻撃・修理・解体を既存の処理で行う。実際に支払った資源を返金計算に使い、破壊や解体後に無料再生しない。途中の支払いと作業量は保存される。

限定チェックで、未知時の非表示、復旧途中/完了/解体後の保存再開、一度だけの支払い、既存建物への置換と足場解放を確認。これは制御した機能検証であり、通常資源の攻略や楽しさの証明ではない。通常費用の新規作戦で、訓練所と追加2人の生産を経て、計4戦闘員が2作業員を護衛。既存キャンプ16体を排除し、94.5秒に復旧、104.55秒に食料20を搬入した。敵削除・部隊瞬間移動・資源注入はこの進行で行っていない。通常倍率の同一カメラで、獲得済みの復旧前と初回搬入後の保存を実Godot描画した。これは作戦クリアや人間によるプレイ評価ではない。

独立レビューで、解体跡がスマホのタップを拾う不具合を発見し修正。移動命令が届くことを確認。M1/M3の施設構成と新規保存、M2の探索・標的・勝敗・保存の既存回帰を確認した。短時間headless終了のObjectDB警告は残る。

証拠は[evidence](evidence/frontier_depot_rebuild/)。機能確認は `tests/check_frontier_depot.gd -- --touch-ui-size=844x390`、通常費用の進行は `tests/play_frontier_depot.gd`（DEPOT_EVIDENCE環境変数に書込み可能な出力ディレクトリを指定）。
