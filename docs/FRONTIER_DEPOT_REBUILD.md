# 任意の前線倉庫（再構築・検証途中）

第2作戦の北西資源地に、作業員で復旧できる廃棄倉庫を追加する試作。廃材50・部品10、作業員1人の基準作業時間12秒。通常の集積所新設は廃材60・25秒。固定位置を早く使うか、部品を使わず自由な場所に建てるかを選ぶ。勝利条件は感染源の破壊のまま。

未探索では非表示。近くには既存の感染者キャンプがあり、復旧地点は安全を保証しない。復旧後は通常の資材集積所になり、搬入・被攻撃・修理・解体を既存の処理で行う。実際に支払った資源を返金計算に使い、破壊や解体後に無料再生しない。途中の支払いと作業量は保存される。

初期の限定チェックで、未知時の非表示、復旧途中/完了/解体後の保存再開、一度だけの支払い、既存建物への置換と足場解放を確認。これは制御した機能検証であり、通常資源の攻略や楽しさの証明ではない。通常の偵察・護衛・復旧・搬入と実画面の確認はまだ未完了。

以前の未保存成果の完全復元ではなく、確認できた基点から新しく実装した候補。旧証拠はこの候補の検証結果へ流用しない。実スマホ/Web/Macは未確認。
