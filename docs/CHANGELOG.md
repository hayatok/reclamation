# 変更履歴

## 0.3

- 初回作戦の短い案内を、時間ではなく実行した行動で進める形式へ変更。
- 選択部隊の命令と、発電開始による初回増援を明示。
- 作戦3の二方向襲撃を警報・レーダー・ミニマップに正しく反映。
- 装備に現在値→採用後の値と、決戦装備の前提を表示。
- 工廠の停止理由と、予備弾の威力40%を表示。
- 重要警告と改装音に専用の音声枠を確保。
- 非致死命中に局所的な反動・火花を追加。元の敵材質は保持。

## 0.2

- 軍団強化を8種から24種へ拡張。数値・上限・前提・抽選をデータ化。
- 雷光網、連鎖解体、地平線斉射、歩く工廠を実装。
- 3系統の構成が異なる部隊・補給・配置で成立するよう検証。
- 弾薬、送電距離・容量、工廠の資材消費、中継レーダー、生産予約を追加。
- 作戦ごとの実際の遮蔽物・通路と、疾走体・重装体を含む襲撃構成を追加。
- 設備起動前は準備時間を確保。作戦ごとの強い圧力は設備起動後に適用。
- 地面を横切る貫通・斉射、死亡時の補修、条件付き威力、塔への補給効果を修正。
- 工業地区を煤けたコンクリート・鉄・黄土色の色調へ更新。
- HUDを資源バー、ミニマップ、選択対象と3D指令アイコンへ整理。
- 装備選択を用途別の図解付き仕様票へ変更。
- 敵のモデルと歩行を保ち、大群をMultiMeshでまとめ描き。
