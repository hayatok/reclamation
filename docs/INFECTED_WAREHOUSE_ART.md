# 倉庫を侵食する感染源

丸い独立した塊を、破れた倉庫を貫く一体の感染塊へ変更した。通常倍率で見える大きい暗い開口、裂けた縁と繊維状の支えを作り、残った屋根と荷役口が元の建物の用途を残す。警戒時は開口の内側だけが赤く変わり、破壊後は低く潰れた瓦礫になる。

獲得済みM2終盤保存の同じカメラ50で実Godotの前後画像を比較し、独立レビューで普通の戦場距離でも一体の感染源として読み取りやすくなったと受入した。警戒と破壊の画像は同じ停止場面に見た目の状態だけを適用した表示fixtureであり、その瞬間の通常プレイの記録ではない。警戒表示が暗すぎた初稿は開口内部の発光だけを一度調整した。実戦の予告時間や出現する敵は変えていない。

元の獲得済み保存の命令を再生すると、旧/新モデルとも785.55秒・316撃破で同じ勝利になり、途中を含む7つの全保存状態が一致した。モデル変更で戦闘・移動・乱数・資源・勝利条件が変わらないことの確認であり、人間の楽しさの証明ではない。

生存状態3352・破壊状態2924三角形、各2面。最大半径4.267m、元の半径4.5mと入口中心6.2mの間に収まり、当たり範囲と出現位置を維持する。実場面40停止フレームの中央値は全画面draw calls299→299、primitives89597→89745。描画量の小さい増加を伴う見た目改善で、FPS改善や実Web/スマホ性能は未確認。
