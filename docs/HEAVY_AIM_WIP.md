# 重火器の照準: 未公開の作業保存

自動射撃の爆薬手・車載砲・固定迫撃砲が既存の爆発半径内の敵密度を評価する試作です。歩兵・監視塔は従来通り。手動集中攻撃、威力、弾数、弾薬、射程、飛翔時間、強化は変えません。

最初の正規保存再生では276体の群れに対して重火器の主射撃10→7回、消費30→21、発射時の範囲内敵数平均14.2→49.4。群れの全滅は約0.5秒遅いため、勝利速度向上の証明ではありません。照準処理は追加コストがあり、1ステップで空間情報を共有します。24候補/64体の評価上限を持つ近似です。

まだ実描画の前後・手動指定の統合回帰・配布を確認中です。このcheckpointは完成版や公開版ではありません。
