# 復旧前後を形で読む搬入所

廃棄倉庫の「暗くした同じ建物に板を足す」外観を、自作の壊れた荷役小屋へ変更した。屋根の大きな欠損と露出した梁が、復旧後には継ぎ当て屋根と使える荷役口に変わる。通常の資材集積所と選択欄の画像も同じモデルに揃えた。

通常倍率50・1180×737の実ゲーム画面で、同じ獲得済み保存とカメラを使い前後比較した。独立レビューでも、屋根の欠損→復旧が通常距離で読め、搬入用途も前より分かると確認。細かな通り抜け構造まで一目で伝わるとは断定しない。

建築範囲3.6×3.2mは同一。各モデルは1つのopaque material/surfaceで、未復旧2648・完成4848三角形。既存のsettlement atlasを外部参照し、新しい画像texture一式は増やしていない。実GPUのtexture割当量は未測定。

停止した通常場面60フレームの中央値では、未復旧の全画面draw callsが189→185、primitivesが40131→37079。完成後は184→184、39535→38727。これは描画量の確認で、ゲームプレイFPSや実Web/スマホ性能の向上を証明しない。ゲームの費用・進捗・HP・攻撃・移動は変更していない。保存/返金/スマホの解体跡操作と他作戦の限定回帰も通過した。
