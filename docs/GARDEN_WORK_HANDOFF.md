# 菜園を建てたら食料を採る

## 実際の手間

広域M2の通常セーブから、偵察隊を登録→本部で作業員を2人予約→枯渇待ちの2人を選択→共同菜園を建設→偵察隊へ戻る、という操作を行いました。菜園は完成しても、建設担当は枯渇した部品採取へ戻って停止していました。食料生産を始めるには、その2人へもう一度命令が必要でした。

## 変更

完成した共同菜園の建設担当は、その菜園の食料採取へ進みます。明示的に予約された次の作業・移動があれば、そちらを優先します。古い種類の資源を持っている場合は、その種類のまま搬入してから食料採取へ進みます。建設時の費用・時間・採取速度・容量は変更しません。

通常建物の建設、菜園を含む修理、工事対象の破壊では、従来どおり元の採取へ戻ります。菜園の破壊や解体を完成と見なして、新しい食料を割り当てません。

## 同じ通常費用の比較

`tests/fixtures/freight_scout_3.json` から、同じ2人・同じ配置・通常の建設費・本部生産費で40秒進めました。基準は貨物地区checkpointの変更前main、候補は新しいmainです。資源や部隊を追加せず、成長選択は両方で保留しました。これは保存状態からの自動比較で、人間の初見評価ではありません。

- 両方とも14秒で菜園完成。
- 変更前: 2人は部品の枯渇待ち。40秒後の食料961.88。
- 変更後: 2人は菜園で採取・搬入。40秒後の食料984.88。差23は通常の2回の搬入によるものです。
- 同じ通常距離・1180×737のネイティブ描画で、作業状態と上部の食料担当人数が一致することを確認しました。
