# 拠点を育てる

## 最初の流れ
1. 本部を選び、作業員を予約する。本部を選択したまま資源を右クリックすると、新しい作業員はそこへ採取に向かう。
2. 作業員を選び、食料・廃材・部品を右クリック。持てる量を集めたら本部または集積所へ運び、搬入した分が備蓄に加わる。
3. 作業員の建築メニューから住居を建てる。1軒で人口上限+5。上限に達した生産は完成待ちになり、枠が空くと進む。
4. 訓練所で生存者を増やす。作業員の増員・採取・建築と、訓練所の軍備を並行して進める。
5. 住居2軒、集積所、訓練所が完成したら、本部で段階IIへ発展。研究中も別の建物は生産を続ける。

最初の6人を食料3・廃材2・部品1に分けると、3資源の役割を把握しやすい。これは固定手順ではない。増員、軍備、建築、発展のどこへ先に使うかを判断する。

## 資源と安全な拡張
- 食料: 作業員と部隊の増員、拠点の発展。最初の備蓄が減ったら菜園を用意する。
- 廃材: 住居・生産施設・防衛施設、修理、弾薬生産。
- 部品: 発展、動力設備、爆薬手、車両や重火器。
- 集積所は3資源を受け取る。資源の近くに建てると、運搬時間を短縮できる。
- 資源が尽きた作業員は14m以内の同種資源へ移る。近くに残っていなければ待機表示になる。遠い採取場への移動はプレイヤーが指示する。
- 遠い採取場には集積所と護衛も必要になる。軍を拠点に集めるだけでは、拡張先の作業員や住居を守れない。
- 作業員に建築をさせると、完成後は直前の採取へ戻る。新しい移動命令などを出した場合は、その命令を優先する。

## 生産と発展
- 本部: 作業員、段階II・IIIへの発展。
- 訓練所: 生存者。段階IIから爆薬手。
- 車両工房: 補給車。段階IIIから移動迫撃車。生産には給電が必要。
- 弾薬工房: 廃材を使い、戦闘用の弾薬を補充する。
- 建物ごとの予約は独立して進む。予約時に費用を払い、取消時はその予約の費用を返す。
- 家を失って上限超過になっても、既存の仲間は消えない。新しい部隊の完成が人口枠回復まで待つ。
- 発展の必要施設と費用は本部のコマンドに表示される。段階IIIには稼働中の弾薬工房と車両工房が必要。

発電と生産の拡大は群れを引き寄せる。経済を育てた先では、共有XPの強化を組み合わせ、電撃連鎖・誘爆・多連装砲撃で大群を押し返す。
