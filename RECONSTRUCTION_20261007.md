# Character improvement reconstruction

This is a new reconstruction based on verified published v0.38.0, commit aceed1aacc979b8ed6e86bb84af190b05bc05e82. The original locally validated v0.39 candidate and its distribution files are currently unavailable. This tree is not claimed to reproduce that candidate byte-for-byte.

The WIP actor adapter was recovered from an existing GitHub blob and matched SHA-256 5e852c916b44ab52db1ffaa8e1fc49f252919a970a986897359df0f08c16cc5f. Its articulated-survivor dependency was not recovered and is being newly implemented. Renderer/interpolation/muzzle integration is also being reconstructed. Prior v0.39 screenshots, measurements and test results do not validate this new tree.

Initial scope: basic survivor model and animation only. Normal infected remain the verified v0.38 asset until a separate reconstruction is tested and preserved. No publication or visual acceptance is implied by this work-in-progress source.
